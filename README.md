# QuickResQ React - Practical 3

## Run locally
1. Extract the ZIP.
2. Open this folder in VS Code.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite.

## Practical 3 features
- React functional components and `useState`
- Login, Sign Up and Forgot Password interfaces
- Client-side validation with success/error messages
- Password confirmation during sign up
- Array of service categories and state-managed search history
- JavaScript objects and JSON conversion
- Responsive Bootstrap layout
- Browser Geolocation API demonstration

## Important limitation
Authentication and password recovery are frontend demonstrations only. Account data is not saved to a database, no real email is sent, and emergency-resource data is not connected to a backend.
